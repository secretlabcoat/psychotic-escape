How to play
  1. Click the Mac screen once so it captures the mouse.
  2. Double-click the Psychotic floppy, then Psychotic!.
  3. Type two-word commands like LOOK, GO WEST, OPEN GATE.
  4. Use the COMMANDS and WEAPONS menus when they appear.
