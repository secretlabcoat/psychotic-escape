# Psychotic!

Browser build of **Psychotic! (The Escape)** — the 2000 Macintosh WAGE adventure — via [ScummVM](https://www.scummvm.org/).

Open the GitHub Pages site, wait for ScummVM to load, click **CLICK HERE TO BEGIN** twice (title + INFO), then type commands like `LOOK`.

Built with the ScummVM WebAssembly runtime; WAGE engine plugin included.
